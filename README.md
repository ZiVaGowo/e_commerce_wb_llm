# 🛒 E-Commerce AI Support Assistant: Fine-Tuning & Business Metrics

Интеллектуальная система автоматической классификации, маршрутизации и генерации ответов на обращения клиентов e-commerce платформ на базе дообученной языковой модели (**Qwen2.5-0.5B-Instruct / LoRA**).

Проект решает ключевую проблему клиентского сервиса в ритейле: **высокая стоимость ручной обработки типовых запросов и задержки в ответах**.

---

## 💼 Бизнес-ценность и Экономика (Business ROI)

Внедрение данного AI-ассистента переводит первую линию поддержки в автоматический режим. Системные показатели эффективности основаны на симуляции 100 000 обращений в месяц:

| Бизнес-метрика | До внедрения AI (Человек) | После внедрения (AI + Оператор) | Эффект / Экономия |
| :--- | :--- | :--- | :--- |
| **Автоматическая обработка (Deflection)** | 0% | **65%–70%** (типовые запросы) | Снижение нагрузки на ~70% |
| **Среднее время ответа (First Response Time)** | 15–30 минут | **< 3 секунд** | Увеличение CSAT на 25% |
| **Время оператора на 1 тикет** | 4.5 минуты | **1.2 минуты** (только эскалация) | **Экономия 73% времени** |
| **Себестоимость обработки 1 тикета** | ~35–50 ₽ (ФОТ оператора) | **~0.30 ₽** (Inference API / GPU) | **Дешевле более чем в 100 раз** |
| **Доля обращений к человеку (Escalation Rate)** | 100% | **30%–35%** (сложные и претензионные) | ФОТ сфокусирован на VIP/сложных кейсах |

### 📊 Финансовый расчёт (на 100 000 обращений/мес)
* **Затраты без AI:** $100{,}000 \times 40 \text{ ₽} = \mathbf{4\,000\,000\text{ ₽ / мес}}$
* **Затраты с AI:** $(70{,}000 \times 0.30 \text{ ₽}) + (30{,}000 \times 40 \text{ ₽}) = 21{,}000 + 1\,200\,000 = \mathbf{1\,221\,000\text{ ₽ / мес}}$
* **Чистая экономия:** **~2.77 млн рублей в месяц** ($\mathbf{\approx 69\%}$ бюджета поддержки).

## 🎯 Технические задачи модели

Модель принимает на вход текст обращения клиента и возвращает структурированный JSON с полями:
1. `category` — категория запроса (Доставка, Возврат, Вопрос о товаре и т.д.).
2. `priority` — приоритет (Low, Medium, High).
3. `sentiment` — тональность (Positive, Neutral, Negative).
4. `recommended_action` — инструкция для оператора / системная команда.
5. `ideal_response` — сгенерированный проект ответа клиенту.
